Prerequisite

Install Python

This tool runs on Python, so it needs to be on your computer first. Installing Python isn't part of the tool itself.

New to it? Watch the walkthrough on YouTube. 

$ python --version
Python 3.12.4
Step 1

Download the tool

Get the project from GitHub and unzip it somewhere you'll find again. 

$ git clone https://github.com/raushanraj00/skip_course_by_rau.git
Step 2 · Interactive

Copy your Coursera cookies

Log in to your Coursera account, then pull three values from your browser:

  1. Right-click anywhere on the page and choose Inspect.
  2. Open the Application tab.
  3. Select Cookies → coursera.org.
  4. Copy these three values:
    • CAUTH
    • CSRF3-Token
    • __204u
✓
On macOS this is automatic

You don't need to create config.json yourself — the command pulls your cookies straight from Chrome.

!
Generate before you save

Click Generate JSON first, then Save config.json. The file downloads to your Downloads folder.

✓
Nothing leaves your browser

These three fields run entirely on this page. No cookie value is uploaded anywhere.

        Step 5
        
Install requirements

        
Open the downloaded project in VS Code.

        

          Go to the project folder, right-click inside it, and choose
          Open in Terminal or Open in Command Prompt. Then run:
        

        
$ pip install -r requirements.txt


        

          !
          

            If the terminal keeps running
            
Once the install finishes, press Ctrl + C to stop it.

          

        


        

          !
          

            Stuck on pyproject.toml?
            
Kill the process with Ctrl + C, then run the same command again.

          

        

      


      
      

        Step 6 · Final
        
Run the tool

        
Pass the slug you extracted in Step 4:

        
$ python -m raushan.main "your-course-slug"


        
For example:

        
$ python -m raushan.main "machine-Learning"


        

          ✓
          

            Module not found?
            
Install whatever module the error names, then run the command again:

          

        


        
$ pip install httpx
# or, if that doesn't work
$ python3 -m pip install httpx
